# 만두 (Mandu)

광고 없는 Windows 압축 프로그램입니다.

## 내려받기

[최신 버전 내려받기](https://github.com/minedchobo/Mandu/releases/latest) → `Mandu-x.y.z-setup.exe` 를 받아 실행하세요.

- 정식 코드 서명 인증서가 없어서 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행** 을 누르면 됩니다.
- 한 번 설치하면 새 버전이 나올 때 만두가 알림으로 알려 줍니다. 알림을 누르면 바뀐 점을 보고 바로 업데이트할 수 있습니다.
- 받은 파일이 맞는지 확인하려면 같은 릴리스의 `.sha256` 파일과 비교하세요.

## 할 수 있는 것

- ZIP · 7Z · RAR · EGG · ALZ · TAR · GZ 등 압축 풀기, ZIP · 7Z · 자동 풀림 EXE 등으로 압축하기
- 탐색기 우클릭: 여기에 풀기 / "이름" 에 풀기 / 이름.zip 으로 압축하기 …
- 자동 풀림 압축 파일: 더블클릭하면 그 자리에 풀리고 스스로 사라지는 `.exe` (만두가 없는 PC 에서도 동작)
- 압축 파일 미리 보기, 테스트, 손상된 ZIP 복구, 암호 관리자

이 저장소에는 설치 파일만 올립니다.
